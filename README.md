# 桌面工具 (desktop-tool)

一个基于 Electron 的桌面托盘工具，提供 HTML 渲染、JSON 格式化、CURL → Python 转换及时间戳辅助等开发常用功能。

## 功能

- **Render HTML**：将剪贴板中的 HTML 渲染为独立窗口
- **JSON 格式化**：格式化剪贴板中的 JSON，并自动复制回剪贴板
- **CURL → Python**：将剪贴板中的 curl 命令转换为 Python requests 代码，支持直接执行并查看响应
- **时间戳辅助**：菜单实时显示当前时间戳；中键识别剪贴板中的时间戳并展示日历时间

## 使用说明

1. 启动应用（`npm start`），应用驻留系统托盘
2. 按 `Ctrl+Shift+H` 或点击托盘图标 / 按鼠标中键，弹出快捷菜单
3. 菜单操作：
   - 🌐 Render HTML：渲染剪贴板中的 HTML
   - 📋 JSON 格式化：格式化剪贴板中的 JSON
   - 🐍 CURL → Python：转换剪贴板中的 curl 命令
   - ⏱ 时间戳栏目：显示当前秒级/毫秒级时间戳，点击复制
4. 鼠标中键智能识别：若剪贴板为 10 位（秒）或 13 位（毫秒）纯数字时间戳，则弹出日历时间弹窗（本地/UTC/相对时间，可点击复制）；否则打开快捷菜单

### Render HTML 窗口搜索

在渲染结果窗口中按 `Ctrl+F` 或 `F3` 弹出搜索工具条：输入即时搜索、显示 n/m 匹配计数、▲▼ 或 Enter/Shift+Enter 循环导航、Esc 关闭并清除高亮。

### CURL → Python 响应搜索

点击「执行」后，响应面板右上角出现搜索框：输入即时高亮、Enter/Shift+Enter 或 ▲▼ 循环导航（当前匹配红色高亮并自动滚动居中）、✕ 或 Esc 清除。

## 打包

```bash
npm run dist
```

输出到 `release/` 目录：

- `桌面工具 <版本>.exe` — portable 免安装版
- `桌面工具 Setup <版本>.exe` — NSIS 安装版
